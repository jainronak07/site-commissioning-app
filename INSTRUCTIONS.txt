## 🚀 How to Run Locally

### Prerequisites

Ensure the following are installed on your local machine:

* [Node.js](https://nodejs.org/) — v18 or higher
* [Git](https://git-scm.com/)
* **Expo Go** app on your physical iOS/Android device, or an iOS Simulator / Android Emulator

### Installation & Setup

1. **Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/site-commissioning-app.git
```

2. **Navigate to the project directory**

```bash
cd site-commissioning-app
```

3. **Install dependencies**

```bash
npm install
```

4. **Start the Expo development server**

```bash
npx expo start -c
```

### 📱 Running the App with Expo Go

To test the app on a physical device:

1. Install the **Expo Go** app from the iOS App Store or Google Play Store.
2. Ensure your phone and computer are connected to the **same Wi-Fi network**.
3. Start the development server using:

```bash
npx expo start -c
```

4. Scan the QR code displayed in the terminal.

* **iOS:** Open the default Camera app, scan the QR code, and tap the Expo Go prompt.
* **Android:** Open the Expo Go app, select **Scan QR Code**, and scan the QR code displayed on your computer.

Your app should now open in Expo Go and be ready for testing.
